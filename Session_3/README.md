# Hệ thống Phân phối vé và Điều phối hậu cần Phòng chiếu phim

Đây là bài tập JavaScript cơ bản, áp dụng các kiến thức về khai báo biến và cấu trúc rẽ nhánh (`if/else`, `switch/case`, toán tử ba ngôi).

## Các file trong dự án
- `index.html`: File giao diện web cơ bản, dùng để nhúng và chạy mã JavaScript.
- `ticket_logistics_distribution.js`: File chứa mã nguồn chính xử lý logic tính tiền vé.

## Hướng dẫn chạy thử
1. Mở file `index.html` bằng trình duyệt web (Google Chrome, Cốc Cốc, Edge...).
2. Nhấn phím `F12` để mở công cụ dành cho nhà phát triển (Developer Tools).
3. Chuyển sang tab **Console** để xem phiếu điều phối hậu cần và giá vé.
4. Bạn có thể mở file `ticket_logistics_distribution.js` và thay đổi các giá trị biến từ dòng 1 đến dòng 8 để thử các trường hợp dữ liệu khác nhau.
